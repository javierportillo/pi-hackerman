# @javiportillo/hackerman

Hackerman theme port based on the **Hackerman Theme for Visual Studio Code** theme by **Marcos Coimbra**.

*A neon hacker-style color theme* for your pi coding agent.

## Install

```shell
pi install npm:@javiportillo/pi-hackerman
```

Or try without installing

```shell
pi -e npm:@javiportillo/pi-hackerman
```

Then select a theme via `/settings`

## Uninstall

```shell
pi remove @javiportillo/pi-hackerman
```
